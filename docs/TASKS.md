# План на один день

| Время | Работа и результат |
|---|---|
| 0–1 ч | Артур раскрывает исходники, утверждает контракт и публикует основу веток после согласования. Проверить независимую конфигурацию Firebase. |
| 1–4 ч | Алимжан собирает одну разрешённую категорию OLX. Алинур готовит расчёт на маркированных фикстурах. Улан строит UI на контрактных данных. Артур подключает API, каталог и навигацию. |
| 4–6 ч | Свести сбор, серверное сохранение, расчёт и UI в MarketLens. Проверить 3 оригинала, цены, фильтры, группы и отсутствие дублей. |
| 6–8 ч | Репетиция и стабилизация P0. После подтверждения P0 подключить опциональный Gemini, дополнительные фильтры и визуализацию. |

- Артур, feat/core. Готово, когда новый runtime изолирован от Saq, а каталог,
  навигация и API работают через общий контракт. При отключённом Gemini
  расчёты доступны, а пояснение возвращается локально.
- Алимжан, feat/parsers. Реальные записи OLX с проверяемыми оригиналами и
  каноническими ID. Повторный импорт не дублирует карточки. Отказ источника
  виден, без подстановки фикстур. Krisha/Kolesa только после стабильного P0.
- Алинур, feat/analytics. Тесты для выбросов, отсутствующей цены, маленькой
  выборки, смешанных валют и повторного расчёта. В дифференциале знак
  документирован, причина риска объяснима, raw Listing не перезаписывается.
- Улан, feat/dashboard. Обзор, распределение цен, сравнение и представление
  выгодных предложений на серверных показателях. Пустые состояния,
  адаптивность и явная маркировка ограничений.

Перед показом: прогнать Ruff/pytest, Vitest/сборку, пройти OLX → Firestore →
каталог → сравнение → оригинал. История в UI и новые источники относятся к P2.
