# Архитектура MarketLens

Разрешённый публичный источник → серверный адаптер → нормализованные Listing →
серверная запись карточки и снимка в выделенный Firestore → расчёт аналитики →
отдельные AnalysisResult и MarketStats → защищённый FastAPI → React.

## Аудит Saq Qurylys

- Переиспользуем FastAPI, настройку CORS, ошибки и request ID из app/main.py,
  FirebaseRuntime, проверку токена и /me. MarketLens подключает свои маршруты
  через отдельную точку входа. Старые рабочие маршруты не монтируются в ней.
- Firebase Auth, API-клиент, React Router, RouteBoundary, WorkspaceUI и
  Tailwind остаются. Для MarketLens предусмотрен отдельный Vite mode.
  Старый режим сохраняет экран Saq. Паттерны каталога и фильтров берём из
  ComplexList и AdvertisingPage. Модели ЖК, скоринг R1–R6, реестры, PDF,
  данные seed и городскую карту оставляем в старом продукте.
- public_sources.py, monitoring.py и company_sources.py показывают паттерны
  получения и нормализации источников. Текущие коллекторы и рекламные модели
  специализированы под прежний продукт. Для OLX используется новый адаптер.
- Старые CI, Compose и релизные команды сохраняются. Firebase rules уже
  закрывают клиентский доступ ко всем коллекциям. Развёртывайте правила
  отдельно с явным проектом MarketLens. Для OLX production-сбор не запускается
  автоматически. Интеграция запускается вручную из доверенного backend.

## Изоляция

Используйте выделенный Firebase project ID с префиксом marketlens- или
demo-marketlens-. MarketLens читает серверные настройки с префиксом
MARKETLENS_ из окружения или файла .env.marketlens.local, без старого .env.
Веб-клиент в режиме marketlens принимает собственные VITE_MARKETLENS_*.
Выдайте backend отдельный service account с доступом только к MarketLens.
Право на сервисную запись есть только на backend. Ключи и пароли держите
за пределами Git. Firebase Auth использует существующие роли analyst и admin.

Gemini получает только структурированные вычисленные поля. Ссылка, заголовок,
описание и другие свободные поля источника в этот запрос не передаются.
При отсутствии ключа, таймауте или ошибке формы сервер возвращает локальное
объяснение. Ответ модели остаётся вспомогательным текстом, а рассчитанные
показатели сохраняют приоритет.
