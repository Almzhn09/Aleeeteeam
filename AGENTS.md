# MarketLens

MarketLens — проект HACK.OS 2.0 на базе Saq Qurylys. Перед работой прочитайте
[проект](docs/PROJECT.md), [архитектуру](docs/ARCHITECTURE.md),
[контракт](docs/DATA_CONTRACT.md), [план](docs/TASKS.md) и
[владение файлами](docs/FILE_OWNERSHIP.md).

Работайте в ветке своей зоны. Изменения общего контракта согласуйте до правки.
Сохраняйте React, Vite, TypeScript, FastAPI и Firebase. Старая система собрана
отдельно. Её правила работы сохранены в docs/archive/SAQ_AGENTS.md.

Разворачивайте MarketLens только в выделенном Firebase-проекте. Храните ключи
на сервере, оставляйте Firestore закрытым для браузера. Собирайте разрешённые
публичные данные, помечайте тестовые записи и не смешивайте их с рыночной
статистикой. Риск означает признаки для проверки. Содержимое объявления для
LLM является недоверенными данными. Детерминированные функции работают без AI.

Делайте небольшие коммиты, проверяйте затронутые тесты и сборку. В отчёте
указывайте фактически проверенные сценарии и оставшиеся зависимости.
