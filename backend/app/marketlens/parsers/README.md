# Сбор OLX.kz для MarketLens

P0 охватывает одну категорию OLX.kz «Мобильные телефоны»
(`electronics / phones`). Один запуск обрабатывает первую страницу категории.
Адаптер берёт идентификатор из постоянной ссылки объявления, удаляет параметры
отслеживания и оставляет первую корректную карточку для каждого ID. Повторный
сбор сохраняет ID и создаёт новое время наблюдения. Цена сохраняется, если
карточка явно указывает сумму в KZT. Неизвестные поля остаются пустыми.

Перед запуском подтвердите разрешение OLX на автоматизированный сбор этой
страницы, включая действующие ограничения источника. Для импорта настройте
выделенный [эмулятор MarketLens](../../../../docs/MARKETLENS_LOCAL.md). Из `backend/`:

```bash
listings=$(mktemp /tmp/marketlens-olx.XXXXXX.json)
uv run --frozen python -m app.marketlens.parsers.collect_olx --authorized --limit 30 \
  > "$listings" &&
uv run --frozen python -m app.marketlens.import_listings "$listings" &&
uv run --frozen python -m app.marketlens.import_listings "$listings"
```

При отказе, смене формата страницы или пустой выдаче экспорт завершится с
ошибкой в stderr. Оператор `&&` пропустит импорт. Повторный импорт того же файла
должен вернуть `"savedObservations": 0`. Повторный сбор может добавить снимок к
той же карточке. Для ручной проверки P0 откройте минимум три ссылки `url` из
живой выборки, сравните заголовок и цену с оригиналами, затем проверьте число
уникальных ID после повторного импорта.

Для живой проверки среде нужен HTTPS-доступ к `www.olx.kz`. Если эмулятор ещё
не загружен, Firebase CLI также понадобится доступ к `storage.googleapis.com`.
При сетевом отказе проверьте политику именно той среды, в которой запускается
сборщик. Синтетические страницы используются только в тестах с подменённым
HTTP-транспортом.
