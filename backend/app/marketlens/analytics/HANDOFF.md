# Аналитика · заметка для команды

От Алинура (`feat/analytics`). Подробности: [README модуля](README.md).

## Артуру

- `analyze_store` уже подключён через `refresh_analytics` — спасибо. Ничего
  менять не нужно: контракт и методы `MarketStore` те же.
- Изменение v1 после P0: цена сравнивается только внутри одной модели
  (`variant`/`model`, от 4 других объявлений). Группы бренда и категории
  (`electronics/phones:apple:any:KZT`, `electronics/phones:all:any:KZT`)
  приходят только как обзор в `/stats` — их удобно показывать на дашборде как
  распределение по брендам. Карточки без своей модели получают `analysis` с
  `marketPrice = null` и `riskLevel = "unknown"`, если нет текстовых признаков.
- «Обмен» без цены больше не повышает риск: `missing_price` остаётся
  пояснением с 0 баллов.

## Алиму

- Для аналитики самое полезное следующее — сбор нескольких страниц категории
  (100–300 карточек). На 30 карточках у большинства моделей нет 4 сравнимых
  объявлений, поэтому оценки и выгодные предложения будут редкими.
- С моей машины OLX отвечает 403 даже на главную. Если у тебя сбор работает,
  прогони на своём `listings.json`:

  ```bash
  uv run --frozen python -m app.marketlens.analytics listings.json > analysis.json
  ```

  и посмотри, сколько `results` имеют `marketPrice` — по этому подстроим
  распознавание моделей.
